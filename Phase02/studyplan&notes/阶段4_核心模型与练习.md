### 怎样从回溯接到DP

阶段3通常记录一条具体选择历史；DP考虑的是：不同历史到达同一个子问题后，后面的选择是否完全相同。

例如，在“前 i 个位置选不相邻元素”中，枚举所有已选下标会产生指数级分支；换成“前 i 个位置的最大收益”后，最优答案可以按是否选择位置i，归结到较短前缀。不同分支反复需要的 `F(i-2)` 只计算一次。

注意，**累计答案不一定要成为状态下标**。若函数返回“后面还能取得的最大收益”，前面已经取得的收益由调用者加上即可；但若前面已经消耗了会影响后续选择的容量，就需要把剩余容量等信息保留下来。这是阶段5增加维度的原因。

## 模型1：用“前 i 个位置的最优值”处理选或不选

### 代表题：不相邻元素最大和

对应作业：第三阶段编程练习（4）第4题， [原题](https://programming.pku.edu.cn/probset/e91cfb239dde47c1a97f5ad774f3b208/17a9d50cada748a5b78edf957748e76b/)。

原题叙述提到m个元素，但输入没有m，因此不能擅自理解为“恰好选择m个”。原题还没有明确负数范围与是否允许一个也不选。为避免依靠猜测，下面先讲规则完整的训练版：

输入 `0≤n≤10000`，再输入n个整数，`|a[i]|≤10^9`。从中选若干个位置，任意两个被选位置不相邻，**允许一个也不选**。输出最大元素和。没有元素或全负数时，允许输出0。

```text
输入
5
1 2 3 4 5

输出
9
```

### 为什么只记录前缀长度就够了

定义：

> `dp[i]`：只考虑前i个位置，满足不相邻限制时能取得的最大元素和，允许空选。

以位置i是否被选作为分类：

- 不选i：最优值是 `dp[i-1]`。
- 选i：i−1一定不能选，其余位置只需在前i−2个中最优选择，得到 `dp[i-2]+a[i]`。

因此，对 `i≥2`：

$$
dp[i]=\max\{dp[i-1],\ dp[i-2]+a_i\}.
$$

这里不需要另外记录“第i−1个是否选择”。第二个分支直接跳回前i−2个位置，已经保证它没有选择i−1。以后若限制更复杂，才需要重新考虑状态能否这样简化。

初始状态是 `dp[0]=0`，若n≥1，`dp[1]=max(0,a[1])`。数组开n+1，因为“前0个”也是一个有意义的子问题。

### 可直接运行的代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n + 1), dp(n + 1, 0);
    for (int i = 1; i <= n; ++i) cin >> a[i];

    if (n >= 1) dp[1] = max(0LL, a[1]);
    for (int i = 2; i <= n; ++i) {
        dp[i] = max(dp[i - 1], dp[i - 2] + a[i]);
    }
    cout << dp[n] << '\n';
}
```

若从递归写起，就是让 `F(i)` 返回上面同一个子问题的答案；对i≤0返回0，再合并“不选i”和“选i”两个分支。加缓存得到记忆化；观察依赖只指向更小的i，再改成上述循环。三种写法的状态含义应保持一致。

### 正确性、边界和复杂度

所有合法方案恰好属于“选i”或“不选i”之一。两类覆盖全部方案，而且对应的较短前缀都可独立求最优；反过来，将前i−2个中的最优方案与i合并一定合法。因此取两类最大值就得到最优答案。

检查n=0、n=1、全负数、全0，以及 `[2,100,2]`。这题的答案是 `dp[n]`，因为它已经允许最优方案在此前结束，而不要求选到n。

时间 O(n)，DP额外空间 O(n)。本训练版可能取得的和约为 `5×10^12`，所以用 `long long`。能独立解释状态后，可以只保留前两个值，将额外空间减至O(1)。

## 模型2：必须固定结尾，才能自然地延长连续段

### 代表题：最大连续子段和（自拟）

输入 `1≤n≤200000`，再输入n个整数，`|a[i]|≤10^9`。选择一个**非空、连续**的子数组，输出最大元素和。

```text
输入
6
-2 3 -1 2 -5 4

输出
4
```

本题不能跳过中间不喜欢的元素，也不能用空数组得到0。

### “前i个中的最优值”为什么还不能直接拿来延长

若只知道“前i−1个中的最大连续段和”，那一段可能早已结束。直接加a[i]，中间可能跨过没有选的元素，破坏连续性。

所以改为定义：

> `endBest[i]`：所有**必须以位置i结尾**的非空连续子数组中，最大的元素和。

以i结尾的连续段只有两种情况：只含a[i]，或接在一个以i−1结尾的连续段后面。

$$
endBest[i]=\max\{a_i,\ endBest[i-1]+a_i\}.
$$

最后答案是所有结尾中的最大值，而不是只输出 `endBest[n]`。

| i | a[i] | endBest[i] | 到目前为止的整体最优 |
|---|---:|---:|---:|
| 1 | −2 | −2 | −2 |
| 2 | 3 | 3 | 3 |
| 3 | −1 | 2 | 3 |
| 4 | 2 | 4 | 4 |
| 5 | −5 | −1 | 4 |
| 6 | 4 | 4 | 4 |

位置3处的“结尾最优”是2，整体最优却是3。它们负责回答不同的问题。

### 可直接运行的代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n + 1), endBest(n + 1);
    for (int i = 1; i <= n; ++i) cin >> a[i];

    endBest[1] = a[1];
    long long answer = a[1];
    for (int i = 2; i <= n; ++i) {
        endBest[i] = max(a[i], endBest[i - 1] + a[i]);
        answer = max(answer, endBest[i]);
    }
    cout << answer << '\n';
}
```

### 正确性、边界和复杂度

每个以i结尾的非空连续段，如果长度大于1，删掉最后一个元素后，必然是以i−1结尾的非空连续段；保留其中和最大的一个再延长最优。长度等于1的情况由a[i]单独覆盖。因此转移完整。每个非空连续段都有唯一的结尾，枚举所有结尾就不会漏掉全局最优。

`[-5,-2,-7]` 的答案是−2，不是0；n=1时答案就是唯一的元素。不能像允许空选的模型1那样，把所有状态初始化为0后直接取最大值。

时间 O(n)，当前写法空间 O(n)。状态最大绝对值可到 `2×10^14`，用 `long long`。如果只求值，保留上一个 `endBest` 就可以压缩到O(1)额外空间。

## 模型3：枚举最后一部分，剩下的交给较小规模

### 代表题：作业《钢条切割问题》

第三阶段编程练习（4）第1题， [原题](https://programming.pku.edu.cn/probset/e91cfb239dde47c1a97f5ad774f3b208/ed2dda5bcddc44019b362319aea7b566/)。

输入钢条长度n，再输入长度1至n的售价p[1]至p[n]。`1≤n≤3000`，`1≤p[i]≤10000`。切割没有成本，所有长度都是整数，求把整根钢条出售能获得的最大收益。可以不切，也可以切出多个相同长度的段。

```text
输入
7
1 5 8 9 10 17 17

输出
18
```

### 怎样把切法化成一个规模状态

定义：

> `dp[len]`：将长度恰好为len的钢条全部利用、出售，能够取得的最大收益。

考虑最后留出的一段长度piece，它的收入是p[piece]；其余长度len−piece也必须全部利用，最优收益是dp[len−piece]。

$$
dp[len]=\max_{1\le piece\le len}
\{dp[len-piece]+p[piece]\}.
$$

`dp[0]=0` 表示没有剩余钢条，自然没有收入。piece=len时，剩余长度为0，对应完全不切，不需要在转移之外另补一个答案。

样例长度7可以选长度1和6，收入为1+17=18。这个例子用于理解状态，不意味着应该贪心地先选单段售价最高的长度。

### 可直接运行的代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> price(n + 1), dp(n + 1, 0);
    for (int len = 1; len <= n; ++len) cin >> price[len];

    for (int len = 1; len <= n; ++len) {
        dp[len] = price[len];  // 不切割：完整出售这一段
        for (int piece = 1; piece < len; ++piece) {
            dp[len] = max(dp[len], dp[len - piece] + price[piece]);
        }
    }
    cout << dp[n] << '\n';
}
```

代码先用“不切”初始化当前状态，再枚举真正切出较短一段的情况。每个长度都有售价，所以所有dp[len]都可达；初始化为该长度的售价，比把不可达的情况和收益0混在一起更明确。

如果从递归开始写，`best(len)`依次尝试piece=1至len，返回剩余长度的最优收入与当前段收入之和的最大值。同一个剩余长度会从很多切法到达，缓存后只有n+1个规模状态。这里需要理解这一过渡，不必再写三份几乎相同的完整程序。

### 正确性、边界和复杂度

任意完整切法都能取出最后一段；删去它后，若剩余部分没有采用该长度的最优切法，就可以替换它而提高整体收益，且不会影响最后一段。因此每种最后段长都对应一个合法的最优候选，枚举所有段长必然包含整体最优。

有些最终切法会因取出段的顺序不同被重复考虑，但这里只求最大收益，不受影响。若以后改为“统计不同切法数量”，就必须重新确认顺序是否算不同，不能直接把max替换成加法。

时间 O(n²)，空间 O(n)。n=3000时，内层合计约450万次更新，适合本题范围。收益不超过3000×10000，用int也能容纳；示例统一用 `long long`。

检查n=1、不切最优、全切成长度1最优、重复段长最优。不要增加“一个长度只能选一次”的限制；售价表不是只有一件的物品清单。

### 练习：先不给答案

**3A 只能出售指定长度（自拟）。** 输入 `n q`，`1≤n≤3000`，`1≤q≤min(50,n)`。接下来q行，每行一个不同的长度 `1≤len≤n` 和售价 `−10^6≤value≤10^6`。每种长度可重复出售，但钢条必须全部用完，只能切成表中允许的长度。能完成则输出最大收入，否则输出 `Impossible`。允许最优收入为负数。

**3B 每切一刀收费（自拟）。** 输入 `n c`，再输入长度1至n的价格表；`1≤n≤3000`，`0≤c≤10000`，`0≤p[i]≤10000`。每切一刀额外支出c，切成t段共需t−1刀；不切没有切割费。所有钢条必须利用，输出最大净收入。

## 模型4：先消除不必要的约束维度，再按坐标计算

### 代表题：作业《受限时间内的最小通行费》

第四阶段编程练习（2）第7题， [原题](https://programming.pku.edu.cn/probset/1cf57fe2f4504abcbe76d0e44d1077a7/574b21da7ad64bd6bd7c8d9c99d1051e/)。你已有这道题的记忆化代码，下面作为推导与边界复盘，不算新作业。

一个N×N网格，从左上角进入、右下角出去。经过每个格子用1单位时间并缴纳其费用，必须在2N−1单位时间内通过，求最小费用。输入N和费用矩阵，`1≤N<100`，起终点的费用也计入；原题没有给出完整的费用数值范围。

### 为什么没有时间这一维

从左上角到右下角，至少需要向下N−1次、向右N−1次，共2N−2次移动，经过2N−1个格子，恰好用完允许时间。

如果出现一次向上或向左，就必须额外向下或向右补回来，移动次数至少增加2，不再满足限制。因此所有合法路线都只向右或向下。

**时间限制在这里限制了移动方向，并没有留下独立变化的“剩余时间”。** 不必一见时间就开dp[x][y][t]。

### 状态与转移

定义 `dp[i][j]`：从左上角到达(i,j)，且包含该格费用的最小总费用。这里坐标从0开始。

内部格子的上一步只能来自上边或左边：

$$
dp[i][j]=\min\{dp[i-1][j],\ dp[i][j-1]\}+cost[i][j].
$$

左上角直接支付自己的费用；第一行只能从左边来，第一列只能从上边来。先处理这些边界，内部转移就不需要把不存在的路线硬编码成0。

### 可直接运行的代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<vector<long long>> cost(n, vector<long long>(n));
    vector<vector<long long>> dp(n, vector<long long>(n));
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < n; ++j)
            cin >> cost[i][j];

    dp[0][0] = cost[0][0];
    for (int j = 1; j < n; ++j)
        dp[0][j] = dp[0][j - 1] + cost[0][j];
    for (int i = 1; i < n; ++i)
        dp[i][0] = dp[i - 1][0] + cost[i][0];
    for (int i = 1; i < n; ++i) {
        for (int j = 1; j < n; ++j) {
            dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + cost[i][j];
        }
    }
    cout << dp[n - 1][n - 1] << '\n';
}
```

这与笔记里的最小路径和递推相同，新增重点在于从题意推导出“只能向右、向下”。使用 `long long` 扩大了可容纳范围；因为原题没有费用上界，仍应以所有路径和可在64位有符号整数中表示为实现前提。

### 用一个极小输入检查已有代码

如果允许0费用，考虑：

```text
2
0 0
5 0
```

最小费用是0，走右、下即可。但你现有代码用0表示不存在的后续路线，会在比较0与5时选到5。这说明不能仅凭答案为0判断路线不存在。即便评测数据恰好都是正费用，也值得把这项隐含假设写清楚。

若题目有障碍，边界也不再保证可达；这时可用 `INF` 表示不可达，并且只从可达前驱转移。不要无条件计算 `LLONG_MAX + cost`，否则会溢出。模型6会示范带不可达判断的完整写法。

### 正确性、边界和复杂度

每条到内部格子的合法路线，最后一步都来自上或左。最后一格的费用固定，取较小的前驱最优费用再加它就是最优。按行从上往下、每行从左往右计算时，上边和左边都已经求好。

时间、空间均为O(N²)。n=1时，答案是唯一格子的费用；单格也要缴费。允许0费用没有问题。若改为一般四方向自由走且有宽松时间限制，这个坐标转移就不能直接复用。

**4B 只统计路线（自拟）。** 输入 `1≤n,m≤1000`，随后n行长度为m的字符串，`.`可走、`#`为障碍。只能向右或向下，从左上到右下，求不同路线数，对1000000007取模。起终点可能被堵住；若n=m=1且可走，长度为0的移动路线计1种。

**4C 同时统计最便宜路线的条数（自拟，选做）。** 沿用4A格式，改为 `1≤n,m≤500`，正常费用在 `0…10^6`。输出最小费用和达到该费用的路线数，计数对1000000007取模；无路输出 `-1 0`。两条路线经过的坐标序列不同即视为不同。

## 模型5：依赖不按坐标排列时，用记忆化按需求值

### 代表题：作业《滑雪》

第四阶段编程练习（2）第6题， [原题](https://programming.pku.edu.cn/probset/1cf57fe2f4504abcbe76d0e44d1077a7/a888308f5fb94e8386dd66bac917fe55/)。

输入行列数R、C和高度矩阵，`1≤R,C≤100`，`0≤h[i][j]≤10000`。可以从任意格开始，每次滑到上下左右相邻、且高度**严格更低**的格子。输出最长滑行路线包含的格子数。

```text
输入
2 3
6 5 4
1 2 3

输出
6
```

### 先定义一次调用究竟返回什么

> `dfs(x,y)`：从(x,y)出发，能够走出的最长严格下降路线的格子数，包含起点自身。

这里返回的是**从当前点出发的后续最优值**。它不包含此前已滑过的长度，也不必把当前累计长度传进缓存下标。

若没有更低的邻居，仍可停在本格，答案为1。否则，选择一个合法邻居(nx,ny)，得到 `1+dfs(nx,ny)`，在所有邻居中取最大值。

$$
F(x,y)=\max\left(\{1\}\cup
\{1+F(nx,ny)\mid (nx,ny)\text{四邻接且更低}\}\right).
$$

最后在所有起点的F中取最大值。与模型2一样，局部状态的答案不一定就是整题答案。

### 为什么只缓存坐标，不缓存整条历史路径

任何到达当前格的合法路径，其先前格子都比当前格高；此后的格子都比当前格低。后续不可能走回先前路径。因此，从不同路线到达同一个格子，不会改变它以后能选择的下降路线。

同时，沿每条边高度严格下降，不可能转一圈回到原高度。把所有格子视作点、向更低邻居连边，就得到没有有向环的依赖关系，简称DAG。

这两点既说明坐标状态足够，也说明递归一定会在依赖中结束。若把“严格下降”改成“可以持平”，这些依据就需要重新检查。

### 可直接运行的代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int rows, cols;
vector<vector<int>> heightGrid, memo;
const int dx[4] = {-1, 1, 0, 0};
const int dy[4] = {0, 0, -1, 1};

int dfs(int x, int y) {
    if (memo[x][y] != 0) return memo[x][y];

    int best = 1;
    for (int dir = 0; dir < 4; ++dir) {
        int nx = x + dx[dir], ny = y + dy[dir];
        if (nx < 0 || nx >= rows || ny < 0 || ny >= cols) continue;
        if (heightGrid[nx][ny] >= heightGrid[x][y]) continue;
        best = max(best, 1 + dfs(nx, ny));
    }
    memo[x][y] = best;
    return best;
}

int main() {
    cin >> rows >> cols;
    heightGrid.assign(rows, vector<int>(cols));
    memo.assign(rows, vector<int>(cols, 0));
    for (int x = 0; x < rows; ++x)
        for (int y = 0; y < cols; ++y)
            cin >> heightGrid[x][y];

    int answer = 0;
    for (int x = 0; x < rows; ++x)
        for (int y = 0; y < cols; ++y)
            answer = max(answer, dfs(x, y));
    cout << answer << '\n';
}
```

### memo与vis有什么不同

`memo[x][y]` 存的是完整答案。只有所有更低邻居的答案都求出、完成比较后，才把best写入memo。

`memo==0` 在本题可安全表示未计算，因为合法答案至少为1。不能把它理解为“路径长度0”。多个高点可能共用同一个低点的最优后缀，这是缓存带来的节省，不应该禁止另一个起点使用它。

| 对象 | 记录的含义 | 是否恢复 |
|---|---|---|
| 连通块搜索的vis | 此节点已经被本次遍历发现 | 不恢复 |
| 枚举路径的inPath | 此节点在当前路径里 | 返回时恢复 |
| 滑雪的memo | 以此节点为起点的最优值已计算完成 | 不恢复，后续直接复用 |

### 正确性、顺序和复杂度

按高度从低到高考虑。最低处没有合法后继，值为1正确。假设所有更低邻居的答案都正确，从当前点出发的路线要么停下，要么先去其中一个更低邻居；在这些完整选择中取最大值，因此当前答案也正确。这个论证对应记忆化递归的依赖顺序，而不是按输入坐标逐行计算。

每个格子的答案只展开计算一次，每次检查四个方向，总时间O(RC)。缓存和输入各O(RC)；递归栈最坏也为O(RC)，不能只记成O(R+C)。最长路线不超过10000格，int足够。

原范围下仍可能出现深度接近10000的下降长链，实际栈是否够用取决于运行环境。若出现栈限制，可以将格子按高度升序排序，再依次从已算好的更低邻居计算；这种非递归做法的时间为O(RC log(RC))，空间O(RC)，不需要另学通用拓扑排序才能理解。

检查单格、所有高度相同、多起点共用后缀、下降路径绕弯、最优起点不在最高值位置。长度按格子数计，单格是1，不是0步。

## 模型6：完整划分前缀，枚举最后一道分界

### 代表题：带段长与段和限制的分批（自拟）

有按顺序排列的n个对象，每个对象有一个整数数值a[i]，可以为负。必须把**全部对象**划分成若干个非空连续批次，不能改变顺序、不能遗漏。每批最多包含K个对象，且这一批的数值总和必须在 `[-B,B]` 内。求最少批次数，无法完成输出 `Impossible`。

输入第一行 `n K B`，`1≤n≤1500`，`1≤K≤n`，`0≤B≤10^9`；第二行n个整数，`|a[i]|≤10^6`。输出最少批次数或 `Impossible`。

```text
输入
4 3 3
4 -2 1 2

输出
2
```

可以分成 `[4,-2]` 与 `[1,2]`。整个数组长于K，不能只分一批。前缀 `[4]` 虽然单独无法完成，但更长前缀 `[4,-2]` 可以完成。

### 先补一维前缀和

按1开始给数组编号，定义：

$$
S[0]=0,\qquad S[i]=a_1+\cdots+a_i.
$$

那么最后一批若为 `j+1…i`：

$$
\operatorname{sum}(j+1,i)=S[i]-S[j].
$$

S[0]表示空前缀，使从第1个开始的区间也能直接计算。S不是DP表，它只是把一次区间求和变为O(1)；选择最优分批方式仍由下面的DP负责。

### 定义“完整处理”的状态

> `dp[i]`：将前i个对象全部划分为合法批次，所需的最少批次数。若不可能，记为INF。

最后一批之前的分界点是j，最后一批为j+1至i。那么必须同时满足：

- 最后一批非空：j<i。
- 最后一批长度不超过K：i−j≤K。
- 最后一批的和在范围内：−B≤S[i]−S[j]≤B。
- 前j个对象能够完整划分，即dp[j]可达。

合法时尝试 `dp[j]+1`，在所有j中取最小值。空前缀已经完整处理，`dp[0]=0`；其他位置先设为不可达。

$$
dp[i]=\min_{\substack{\max(0,i-K)\le j<i\\
|S[i]-S[j]|\le B\\dp[j]\ne INF}}
\{dp[j]+1\}.
$$

### 可直接运行的代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n, maxLength;
    long long bound;
    cin >> n >> maxLength >> bound;

    vector<long long> prefix(n + 1, 0);
    for (int i = 1; i <= n; ++i) {
        long long value;
        cin >> value;
        prefix[i] = prefix[i - 1] + value;
    }

    const int INF = 1000000000;
    vector<int> dp(n + 1, INF);
    dp[0] = 0;
    for (int i = 1; i <= n; ++i) {
        for (int j = max(0, i - maxLength); j < i; ++j) {
            if (dp[j] == INF) continue;
            long long segmentSum = prefix[i] - prefix[j];
            if (segmentSum < -bound || segmentSum > bound) continue;
            dp[i] = min(dp[i], dp[j] + 1);
        }
    }

    if (dp[n] == INF) cout << "Impossible\n";
    else cout << dp[n] << '\n';
}
```

### 为什么不能跳过不好处理的元素

有时会写出 `dp[i]=dp[i-1]`，以为这叫“不选第i个”。但本题要求前i个对象全部被分批，这样就漏掉了第i个对象。只有存在合法的最后一批，并接在一个已完整处理的前缀后面，才能更新dp[i]。

这与模型1有实质区别：模型1允许不选对象；这里不允许。不能因为都用dp[i]，就给它们相同的初始化和默认转移。

也不能因为某段当前和越界就停止往外扩展：负数可能把它拉回合法区间。例如B=3时，单个4不合法，但 `[4,-2]` 合法。代码枚举全部允许的分界点，不依赖正数的单调性。

### 正确性、边界和复杂度

每个合法完整划分都有唯一的最后分界点j，前j个对象构成一个合法完整划分，最后一批也满足长度和段和限制。因此它一定在枚举中被考虑。反过来，每个更新都把一个完整前缀与一个合法非空最后批次接起来，得到完整合法划分。用其中最少的批次数便得到最优值。

由于j<i，按i从小到大计算即可。若没有任何合法更新，保留INF，不能擅自把它改为0。可行答案至多为n，所以INF取10^9足够；先检查dp[j]再加1，清楚地区分“没有方案”和“一个空前缀需要0批”。

前缀和与数值比较用 `long long`，dp记录批次数用int。时间O(nK)，最坏O(n²)，空间O(n)。用前缀和后没有在每个j内再扫描一遍区间，因此不会退化成O(n³)。

检查n=1、K=1、B=0、全0、单个前缀不可达但后面可达、整段总和合法但长度超限，以及最终无解。

### 它与区间DP的区别

这里每个状态只回答“前i个对象”，j只是一次转移里枚举的决策。**枚举过区间，并不等于状态就是区间DP。** 阶段6的dp[l][r]要回答任意左右边界的子问题，计算顺序也会不同。

### 练习：先不给答案

**6A 不等长词典分词（自拟，已完成作业《分词》的变式）。** 输入 `1≤q≤100`，随后q行不同的小写英文单词，每词长度1至20；最后一行一个长度1至1000的小写字符串。单词长度可以不同，可以重复使用词典单词，必须恰好拼出整个字符串。输出最少使用的单词数，拼不出输出 `Impossible`。原作业词典单词等长，已经完成，不作为这题的新增作业量。

**6B 批次费用改为长度的平方（自拟）。** 输入格式、数值范围和所有合法条件与代表题相同，但目标改为使总费用最小：一批长度为len，其费用是len²，全部批次费用相加。输出最小总费用，无解输出 `Impossible`。不再输出批次数。

## 三、把初始化与合并方式放回状态含义里理解

| 状态含义 | 最小状态/未达到状态 | 合并方式 | 最后读哪里 |
|---|---|---|---|
| 允许空选的前缀最大收益 | dp[0]=0 | max | dp[n] |
| 必须以i结尾的非空连续段 | endBest[1]=a[1]，不能用空段替代 | max | 所有结尾取max |
| 恰好用完长度的最大收益 | dp[0]=0；是否全可达由允许段长决定 | max | dp[n] |
| 到达格子的最小费用 | 起点付本格费用；无路时用INF | min | 题目指定的终点 |
| 从格子出发的最长下降路线 | 每个格子至少能取自身，长度1 | max | 所有起点取max |
| 完整划分前缀的最少段数 | dp[0]=0，其他先INF | min | dp[n]，可能无解 |
| 方案计数（练习中的目标） | 空方案的贡献视题意而定；常见ways[0]=1 | 加法，必要时取模 | 按题目指定的状态 |

“最大值一律初始化0”“计数一律加起来”“访问过就不再管”都不是足够的规则。初始化和合并方法，必须能用状态的完整中文定义解释。

本阶段不要求每题都先写递归、记忆化、递推三套代码。至少完整经历一次从重复调用到缓存的转换；后续题可以直接按依赖写表。滑雪保留记忆化，是因为依赖顺序隐藏在高度中，而非强求所有DP都写成双重循环。

### 两道不标模型的混合练习

以下均为自拟题，先自行决定状态，不给解法。

**混合A：越过损坏的台阶。** 第一行输入n与k，`1≤n≤100000`，`0≤k≤n`；第二行输入n个 `0…10^6` 的费用；第三行输入k个互不相同的损坏台阶编号，编号1至n，k=0时这一行可为空。初始站在0号地面，每次上1级或2级，可以跨过损坏台阶但不能落在上面；落在正常台阶时支付它的费用。必须恰好到达第n级，求最小费用，无法到达输出−1；第n级也可能损坏。

**混合B：排班奖励。** 第一行输入 `1≤n≤1500`，第二行n个整数a[i]，`|a[i]|≤10^6`。接下来输入 `1≤q≤50`，随后q行，每行给出不同的长度len与奖励reward，`1≤len≤n`，`|reward|≤10^6`。必须按原顺序将全部n天分成连续、非空的工作段，每段长度必须出现在表中，且该段a[i]总和必须非负；该段获得表中对应奖励。求最大奖励总和，无法划分输出 `Impossible`。最终奖励可以为负数。

### 进入阶段5前的验收

在不看解答的情况下，能用自己的代码解释下面四点，即可进入14.4，不必把所有选做题做完：

1. **定义**：区分“前i个”“以i结尾”“从(i,j)出发”“前i个完整划分”。
2. **转移**：最后一步/最后一段的分类不漏，且每个候选确实合法；知道哪些枚举重复不影响最优值，但会影响计数。
3. **边界**：正确处理空前缀、非空要求、0值、负答案、不可达状态；不会把“最后位置”单独补成一堆特判。
4. **顺序与规模**：说明依赖为什么无环、为什么已先算好；用状态数×每状态枚举数估算复杂度，记忆化也计算调用栈。

如果新题卡住，先指出卡在“状态定义”“转移分类”“初始化”“实现”哪一处，再决定补哪一道练习。这个阶段最值得巩固的是：**从题目要求推导状态，而不是看见DP就寻找一个长得相似的方程。**
