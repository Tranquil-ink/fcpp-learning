## 06
**先做复杂度估计！数据范围较小时，直接按题意模拟即可，无需思考算法增加难度**  
使用sort复杂度是O(n2logn)：n个切分点，每个切分点排序两段。n≤1000时约107，绰绰有余；若在循环
里用冒泡排序就退化成O(n3)，那就可能无法通过了。

```cpp
int n,a[1005],b[1005];
int main(){
int T;cin>>T;
while (T--){
cin>>n;
for (int i=1;i<=n; ++i)cin >> a[i];
int ans=0;
for (int i=1;i<=n-1; ++i) {
for (int j=1; j<= n; ++j) b[j]=a[j]; //复制原数组
sort(b+1, b + i +1); //前i个
sort(b+i+1, b +n +1); //后n-i个
if (check(1,i) &&check(i+ 1, n))++ans;
}
cout<<ans<< '\n';
}
return 0;
}
```

## 08 动态规划（？）
**核心思想：当单个数列递推比较困难，维护两个数列来递推**

f[i]：前 i 列被完整覆盖
g[i]：前 i 列中，第 i 列只缺右上角一格

只看” 前i列填满”是不够的：一块L横跨两列、只填3格，必然在尚未处理的那一列留一个缺口。
若只记f，就丢失了”第i列缺一格”这种局面，后面的递推算不下去。而缺右上与缺右下互为镜像，
数量相同，所以用一个g就可以了，只是需要在递推下一步摆放方案的时候乘2。

## 输入处理:
### 当间隔符可能有多种
   - 先整行读入s，再逐字符处理
    - 若当前字符为字母，则s = s + cur；
    - else，则先判断当前s非空，若非空则录入s并清空s

```cpp
int best =-1, cnt =0; stringw;
for (int i = 0; i<=(int)s.size();++i) {
if (i < (int)s.size()&& isalpha(s[i]))w+=s[i];
else if (!w.empty()){ best= max(best,rk(w));++cnt;w.clear();}
```
### “如果有逗号，只保留最后一个逗号后的内容”
指标初始化为-1的

int pos =-1;

s= s.substr(pos +1); //只看最后一段

## 数据类型选择
**记住int范围是2.1×10^9，long long是9.2×10^18**
```cpp
int a=100000,b=100000;
long long c=a*b; //错：右边先按int算完再赋值
long long d=1LL*a*b; //对：先转成longlong
```
由于误差比较浮点数是否相等，一般需要定义一个比较小的数eps，abs(x-y)<eps
判断相同。
