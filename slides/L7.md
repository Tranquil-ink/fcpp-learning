## if else注意点
顺序是if -> (else if) （可多个）-> else，顺序不要错

## 多分支语句 switch case
1. **switch 会先根据表达式的值跳转到匹配的 case 标签处，然后从那里开始一直往下执行，直到遇到 break 或者整个 switch 结束。**  
因此要在每个case后加break。  


2. 另外，case 后接常量表达式，不能判断不等式，灵活使用整除等解决
```cpp
num = score / 10;
switch (num)
{
case 10: cout << "A" << endl; break;
case 9: cout << "A" << endl; break;
case 8: cout << "B" << endl; break;
default: cout << "C" << endl;
}
```

## for语句中i++和++i相同
for（初始化；条件判断；增量操作）  
增量操作i++和++i的区别只在于返回值不同，i都是会加1.  
只关心增量操作后i的值，不关心增量操作表达式的返回值。

## break和continue
1. break：跳出最近的for/while/switch
2. continue：结束本次循环，接着立即测试循环控制表达式，判断是否继续执行下一次循环。
## goto
语句标号也是标识符，定名规则与变量名相同
```cpp
end_of_while:; //空语句
goto end_of_while;

int main() //从1加到100
{
    int i = 0, sum = 0;
    i = 1;
loop: 
    sum = sum + i;
    i++;
    if(i <= 100)
        goto loop;
    cout << sum << endl;
    return 0;
}
```
