函数模板：解决多次重载很麻烦
```cpp
template <typename T> //模板紧贴函数，没有分号
T max(T a, T b){}

template <typename  T1, typename T2>
T1 max(T1 a, T2 b){}
```

lambda 表达式：在main函数内部，
```cpp
auto add[](int a, int b){};
add(3, 4);
//按值还是引用传入参数
int x = 10;
auto capture_value [x](){};  
x = 20;
auto capture_ref [&x](){};

capture_value(); //传入的x是10
capture_ref();  //传入的x是20
```
