# 计算概论A：期末预习八阶段学习计划

> 适用对象：大一 C++ 初学者，已学循环、数组、字符串、结构体及部分 STL，正在阅读 Hello 算法的排序部分；尚未系统学习递归、搜索和动态规划。考试按 180 分钟、9 道编程题训练，允许使用 `algorithm` 库。
>
> 目标：建立“提取题目结构 → 选择模型 → 稳定实现 → 独立调试”的能力，覆盖现有两套期末题的基础题、主要模型题和综合难题。完成标准以独立解题与限时表现为准；读完章节或看懂题解不算完成。
>
> 编制依据：仓库第三、第四阶段作业及“2024级、2025级期末考试试题”，Hello 算法在线目录；核对日期：2026-11-06。章节阅读与模型安排是针对本课程重新组织的学习路线。

## 怎样使用这份计划

八阶段是八个能力阶段，**不等于八周，也不要求等量用时**。第六、七阶段可拆成几轮，第八阶段需要专项精讲与整套训练。顺序推进，每次只让 AI 展开当前阶段，不必一次生成全学期题库。

每阶段都写明了前置知识、阅读范围、补充内容、母题组织和验收要求，可以把一个阶段完整复制给 AI。文中的课程题用于定位学习目标，**实际讲解前应读取原题，不能只凭题名猜版本**。原始材料链接见文末；新会话中建议同时附相应作业文件，或让 AI 读取链接。

每个模型默认采用：**1 道代表母题 → 1—2 道同类题 → 1 道改变关键条件的变式**。已有作业能承担这些角色时不另加题。每阶段再安排 2—3 道不标模型的混合题，并在几天后重写一道。题量随掌握情况调整，不机械地每模型做十道。

每张“母题卡”可以包含：适用条件、题意到变量的映射、函数或状态的准确含义、算法骨架、正确性理由、边界、复杂度，以及“改变哪个条件后不能直接照搬”。输出以 C++ 为主，优先使用清楚的函数、数组和常用容器。



已读过的 Hello 算法第 4—6 章按需回看即可。手写哈希表、手写堆、AVL 树不作为后续阶段的前置知识；手写各类排序也不作为进入递归与 DP 的门槛。是否要求指定实现方式，以课程题面为准。

## 八阶段总览

| 阶段 | 学习主线 | 结束时应获得的能力 |
|---|---|---|
| 1 | 递归、分治与复杂度 | 明确一次调用的任务，处理终止条件和输出顺序 |
| 2 | 栈、队列、图与网格遍历 | 识别连通块、可达性、无权最短步数，正确使用访问标记 |
| 3 | 回溯、组合枚举与剪枝 | 不重不漏地枚举方案，理解选择与恢复状态 |
| 4 | DP 入门、线性/网格/前缀划分 | 从暴力递归建立状态、转移、初始值和计算顺序 |
| 5 | 背包、计数与额外状态 | 区分使用次数、容量含义、最优值/计数，掌握循环顺序 |
| 6 | 序列 DP、区间 DP | 处理双序列、二维偏序、区间决策和表达式组合 |
| 7 | 排序贪心、高精度、事件模拟与链表 | 完成考试中实现量较大的题，遵守题目实现限制 |
| 8 | 综合建模、难题衔接与整套考试 | 完成压轴题的完整训练，形成三小时内的选题与调试流程 |

## 阶段 1：递归与分治——先弄清一次调用负责什么

### 入口与具体目标

已会循环、数组、字符串、函数和基础排序；不预设会递归、图、回溯或 DP。目标是能独立定义递归函数的输入、输出和终止条件，并解释“调用前、调用后”分别发生什么。

### 要学的知识点

1. 递归调用与返回、调用栈、局部变量；按值传递与共享变量的区别。
2. 三个问题：本次调用解决什么？规模怎样减小？最小情况怎样直接回答？
3. 递归求结果与递归生成输出；先处理当前部分还是先处理子问题。
4. 区间分解：用下标表示子串或子数组，统一闭区间或左闭右开区间。
5. 数量级：`O(n)`、`O(n log n)`、`O(n²)`、`O(2^n)`；递归深度与总调用次数不同，递归也要计算额外空间。

### 对应 Hello 算法章节

| 章节 | 阅读范围与关联 |
|---|---|
| 2.2 迭代与递归 | 重点是调用栈与递归树；尾递归优化机制暂缓，不假设 C++ 自动消除调用栈 |
| 2.3 时间复杂度、2.4 空间复杂度 | 先掌握常见数量级及递归空间，不要求严格推导所有递推式 |
| 7.1 二叉树、7.2 二叉树遍历 | 先理解根、左右子树和前/中/后序；可用左右孩子编号数组，层序遍历留到阶段 2 |
| 12.1 分治算法；关联 11.6 归并排序 | 先看如何拆分和合并，再看归并过程；不要求先学会快排。12.3 构建树问题暂缓 |

### 需要补充的课程知识

- **按规则递归生成编码**：均匀区间直接输出，否则输出标记并递归两个子区间。区分“构造输出”与“枚举选择”。
- **简单数值递推**：将“拔牙”与爬楼梯对应；看见重复调用，但本阶段先理解原始递归，效率问题在阶段 4 系统解决。
- 递归出口覆盖空范围、单元素和最小合法输入；数组访问前判断范围。

### 建议的母题链

| 模型 | 母题与迁移 | 本阶段深度 |
|---|---|---|
| 求较小问题的返回值 | 小规模递归求和 → 作业“拔牙” | 能画出小规模调用树，正确合并返回值 |
| 递归处理左右子结构 | 小型二叉树遍历 → 归并的拆分与合并 | 看懂递归顺序，不引入复杂指针建树 |
| 按区间规则生成输出 | 先做简化编码 → 期末“字符串转化” | 独立完成原题，包含全 0、全 1、长度 1 等情况 |

“分解因数”虽是递归题，其不重复计数需要阶段 3 的单调选择约束；本阶段不把它当作无前置的第一道递归题。

### 验收与交给 AI 的要求

能够脱离示例写出一种求值递归和“字符串转化”，逐次解释调用与返回；指出朴素“拔牙”为何重复计算。AI 应先用单分支递归建立调用观念，再进入双分支和区间分解；不提前引入记忆化、回溯模板或树形 DP。练习中安排一次递归边界错误定位。

## 阶段 2：栈、队列与遍历——把故事转成位置和连接关系

### 入口与具体目标

已会基础 C++、递归、区间分解和常见复杂度；尚未学回溯或 DP。本阶段学习栈、队列与图的基本表示，能区分“访问整个连通区域”“判断能否到达”“求最少步数”。

### 要学的知识点

1. 栈的后进先出、队列的先进先出，以及 `stack`、`queue` 的基本操作。
2. 图的点、边、有向/无向、邻接表；先用整数编号和 `vector<vector<int>>` 表示。
3. 网格是隐式图：坐标是点，题目允许的移动是边；方向数组与边界检查。
4. DFS 与 BFS；从一个起点遍历和枚举全部起点计数连通块。
5. 访问标记通常在发现节点、递归进入或入队时设置，避免重复入队与环；多组数据重置。
6. 无权图 BFS 的分层与最短步数；可达性只需遍历，不一定需要最短路。

### 对应 Hello 算法章节

| 章节 | 阅读范围与关联 |
|---|---|
| 5.1 栈、5.2 队列 | 熟练库的使用；本阶段不要求分别手写链式和数组式容器 |
| 9.1 图、9.2 图基础操作、9.3 图的遍历 | 理解表示与遍历；将书中对象、指针封装改写成整数编号，图的动态删点删边操作可暂缓 |
| 关联 7.2 二叉树遍历 | 此时补层序遍历，把队列分层与 BFS 对应起来 |

### 需要补充的课程知识

- **四邻接、八邻接和同值连通**：连通条件必须由原题决定。“数组区域数目问题”中 0、1 的区域都要统计。
- **依赖关系的可达节点数**：从指定包出发去重统计，包含起始包；共享依赖只算一次。
- **栈处理后缀表达式**：遇数入栈，遇二元运算弹出右操作数、再弹左操作数，不能交换减法和除法的顺序；课程题使用 `long long`，识别结束符 `@`，出现除 0 输出 `NaN`。
- 大网格可能递归过深，应能改用 BFS 或显式栈；不要求现在掌握复杂的递归模拟技术。

### 建议的母题链

| 模型 | 母题 → 同类题/变式 |
|---|---|
| 网格连通块 | “查看菌落数目” → “图案计数” → “数组区域数目问题” |
| 两点可达与无权最短路 | “孙悟空找师傅”原题只判断能否到达 → 另加要求最少步数的迷宫变式 |
| 普通图可达性 | 整数编号依赖图 → 期末“pip install” |
| 栈式求值 | 单位数后缀表达式 → 作业“后缀表达式”的实际输入版本 |

### 验收与交给 AI 的要求

能独立写连通块和 BFS 最短步数，并把网格遍历迁移到邻接表。至少用“仅对角相邻”“全空/全满”“多个分支共享依赖”“有环的练习图”检验标记规则。AI 不应把所有搜索题都改成回溯；先教图表示再给普通图题。`pip install` 只需统计，不额外要求拓扑排序；带权最短路、并查集不作为本阶段必学内容。

## 阶段 3：回溯与剪枝——枚举方案时怎样不重不漏

### 入口与具体目标

已会递归、DFS/BFS、数组和基础栈队列；尚未学 DP。目标是理解搜索树中每一层决定什么，正确维护部分方案，处理组合、排列、约束与重复方案。

### 要学的知识点

1. 搜索树、当前状态、下一步候选、成功出口与失败出口。
2. “选或不选”与“枚举下一个选择”；固定下标顺序消除选取次序造成的重复。
3. 按值传递的状态自动随返回结束；共享数组、路径和占用标记需要恢复。
4. 排列的使用标记、组合的起始下标、含重复数值时的同层去重。
5. 可行性剪枝：超过目标、剩余位置不足、行列冲突；解释剪枝为何不漏解。
6. 从数据范围判断枚举是否可行；返回存在性、方案数、全部方案的区别。

### 对应 Hello 算法章节

| 章节 | 阅读范围与关联 |
|---|---|
| 13.1 回溯算法、13.2 全排列问题 | 先按具体问题写清楚状态，再总结框架；不先背含糊的通用模板 |
| 13.3 子集和问题 | 分清首个例题“每个元素可多次选”和后续“每个元素至多选一次”的版本，再对应课程题 |
| 13.4 N 皇后问题 | 先用行、列、对角线布尔数组，不引入位运算优化 |

### 需要补充的课程知识

- **棋盘放 k 个棋子**：可跳过某一行，必须同时跟踪当前行和已放数量；不能直接套“每行恰放一个皇后”。
- **因数分解去重**：下一个因数不得小于前一个因数；“整个数自身”也是一种分解。
- **无序集合与有序序列**：相同元素选取结果，是否因顺序不同而算不同方案，必须读题确认。
- “乘积超过目标就剪枝”需要正数等条件；原题若没有保证符号、是否含 0，不能自行补条件。乘法还需检查溢出。

### 建议的母题链

| 模型 | 母题 → 同类题/变式 |
|---|---|
| 子集二选一 | 小规模选数求和 → “集合里的乘法” → “和为定值的子集数” |
| 单调选择去重 | 无序组合生成 → “分解因数” |
| 约束下按层放置 | “棋盘问题” → “八皇后” → “平衡矩阵”作为综合练习 |

本阶段对子集计数先用小规模回溯建立定义；阶段 5 再用 DP 解决金额范围适合的版本。`和为定值的子集数` 第一行元素个数不定，沿用入场检查中的整行解析。

### 验收与交给 AI 的要求

能独立写出子集计数与棋盘放置，解释每一个恢复操作；能给出组合重复计数的反例。AI 应先安排无重复、正整数的小实例，再改变重复使用、重复值或符号条件；不得把“普通图永久访问标记”与“当前方案的占用标记”混用。不要直接跳到邮票设计或状态压缩搜索。

## 阶段 4：动态规划入门——把重复子问题变成可计算的状态

### 入口与具体目标

已会递归、图遍历、回溯枚举及复杂度估算；尚未学背包和序列/区间 DP。目标是能从暴力思路出发，独立写出状态含义、转移、初始化和计算顺序。

### 要学的知识点

1. 暴力递归 → 找出重复子问题 → 记忆化搜索 → 自底向上的递推。
2. 状态必须包含决定后续选择所需的信息；不要把“递归函数的参数很多”直接等同于都要成为状态。
3. 求最优值、可行性、方案数时分别使用 `max/min`、逻辑或、累加；零值可能是合法答案。
4. 空前缀与初始状态；不可能状态用适当的正/负无穷，禁止从不可达状态转移；防止哨兵值运算溢出。
5. 一维前缀和：区间和、首元素和空前缀；包含负数时不能沿用只对正数成立的单调判断。
6. 先保留完整 DP 数组，说明依赖关系，再学习简单滚动数组。

### 对应 Hello 算法章节

| 章节 | 阅读范围与关联 |
|---|---|
| 14.1 初探动态规划 | 完整经历搜索、记忆化和递推，空间优化放在状态含义明确之后 |
| 14.3 DP 解题思路 | 用最小路径和学习定义状态与填写二维表；与阶段 2 的路径搜索比较 |
| 14.2 DP 问题特性 | 先浏览，做过母题后再用具体例子解释最优子结构、重叠子问题和无后效性 |

### 需要补充的课程模型

- **选或不选的线性 DP**：不相邻元素最大和；明确能否一个都不选及全负数的处理。
- **枚举最后一部分**：钢条切割与学习小组。部分大小是决策，剩余规模形成子问题，不要求选择连续编号的某一组同学。
- **最大连续子段和**：区分“必须以当前位置结尾”和“此前整体最优”；为较复杂矩阵题准备基础。
- **前缀划分 DP**：将前 `i` 个元素完整划分，枚举上一分界点 `j`，用前缀和判断最后一段是否满足条件。
- **网格记忆化**：严格下降的高度保证不会成环；访问过与最优值已计算完成是不同含义。

### 建议的母题链

| 学习顺序 | 母题与目标 |
|---|---|
| ① 递归接上 DP | “拔牙”/爬楼梯：三种方法解决同一问题，比较重复计算 |
| ② 局部选择 | “求数组不相邻元素之和的最大值” → 最大连续子段和衔接练习 |
| ③ 枚举最后一部分 | “钢条切割问题” → 期末“学习小组” |
| ④ 网格状态 | 书中最小路径和 → “受限时间内的最小通行费” → “滑雪” |
| ⑤ 前缀划分 | 简单合法分段练习 → 期末“分段”，目标达到 `O(n²)` |

通行费原题的时间限制应先推导为只向右、向下的最短步数路径，不额外增加一个“时间维度”。“分段”必须覆盖整个数组，不能跳过不利元素；让 AI 给出“遇到非负段马上切开”失败的反例。作业不相邻最大和提到 `m`，但输入不提供 `m`；不要擅自变成“恰选 m 个”，若讲变式应明确新增条件。

### 验收与交给 AI 的要求

独立完成一个选择型 DP、一个网格 DP，以及钢条切割到学习小组的迁移；能自行处理分段的 `Impossible`。每题先用一句完整中文定义状态，说明转移的枚举对象及全部初始值。AI 不应只给方程，也不应从一维压缩后的代码开始教学。滑雪需说明严格下降保证依赖无环，不能把 DFS 的永久标记直接当作缓存答案。

## 阶段 5：背包与计数——先区分约束，再决定状态和循环

### 入口与具体目标

已会基本 DP、记忆化、线性/网格 DP、前缀和与前缀划分，能解释不可达状态。尚未学 LIS、LCS、区间 DP。本阶段建立资源限制与计数模型，并开始学习“增加必要的一维状态”。

### 要学的知识点

1. 0-1 背包与完全背包：每件物品至多一次或可重复使用。
2. 容量“不超过”与总量“恰好达到”的区别；最大收益、最少件数、可行性和方案计数。
3. 二维状态到一维压缩；用状态依赖解释 0-1 容量倒序、完全背包容量正序。
4. 计数时区分组合与排列、相同数值的对象是否可区分；不要只背循环顺序口诀。
5. 简单有限数量背包：先枚举使用件数；只有数据规模要求时再学二进制拆分，暂不学单调队列优化。
6. “前 i 个对象、已选 j 个、总量/目标统计 k”中的维度如何取舍，按状态数乘转移次数检查复杂度。

### 对应 Hello 算法章节

| 章节 | 阅读范围与关联 |
|---|---|
| 14.4 0-1 背包问题 | 先二维 DP，再学一维空间优化；对应阶段 3 的选/不选搜索 |

## 阶段 6：序列与区间 DP——从一种状态定义迁移到另一种

### 入口与具体目标

已会基础 DP、前缀和、背包与计数，能写二维表、处理不可达状态和解释计算顺序；会基础排序、递归和 `vector`。本阶段依次学习单序列、双序列、区间三个模型群，不将它们混成一个通用模板。

### 要学的知识点

1. **LIS**：以第 `i` 个元素结尾的最长严格上升子序列；与“前 i 个元素中的整体最优”区别，先掌握 `O(n²)`。
2. **LCS**：两个前缀的最长公共子序列；与连续子串区别，空串对应第 0 行、第 0 列。
3. **编辑与对齐**：从最后一个字符或最后一对字符分析选择；最小编辑代价与最大相似度的目标不同。
4. **区间 DP**：状态表示 `[l,r]`；从两端决策，或枚举最后一个分界点；通常按长度从短到长计算。
5. **回文**：奇数中心、偶数中心扩展；或由内部区间判定外部区间。计数位置不同的子串，不能只统计不同文本。
6. **一个区间返回多个结果**：表达式按最后执行的运算符分开，组合左右结果；这时不是简单地对答案取 `min/max`。

### 对应 Hello 算法章节

| 章节 | 阅读范围与关联 |
|---|---|
| 14.6 编辑距离问题 | 先完整二维 DP；建议先补 LCS 再阅读。空间优化在能独立处理空前缀后再学 |
| 关联 12.1 分治算法 | 用于理解表达式的左右子问题；有重叠时再联系阶段 4 的记忆化 |

### 需要补充的课程模型

本阶段需要专门补 **LIS、LCS、二维偏序、区间 DP、回文中心扩展与表达式结果组合**，它们没有在 Hello 算法中形成与课程对应的完整专题。不要用编辑距离一节代替全部序列 DP。

### 建议的母题链与关键边界

| 顺序 | 母题链 | 实现要求 |
|---|---|---|
| ① 单序列与排序后 DP | 基础 LIS → 期末“叠盘子” | 排序建立处理顺序，转移仍同时检查宽、高严格变大；`n≤1000` 先用 `O(n²)`，不要求二分优化 LIS |
| ② 两个前缀 | “最长公共子序列” → 书中编辑距离 → “碱基的忧伤” | 对齐的边界得分由空位惩罚累积，不能把整张表初始化为 0；核对题目碱基顺序 |
| ③ 从两端取数 | 一行两端取数 → “矩阵取数游戏” | 原题按第 i 次取数乘 **i**，不是乘 `2^i`；剩余长度确定当前次数，各行独立求解后相加 |
| ④ 枚举区间分界 | 小规模合并 → “石子归并” | 前缀和计算区间总重量；确认是线性排列还是环形版本 |
| ⑤ 回文计数 | 普通回文中心扩展 → 期末“通配回文” | 两端字符相等或任一端为 `?` 即可匹配，包含单字符，目标 `O(n²)`，适配长度 500 |
| ⑥ 区间返回结果集合 | 2—4 个运算符的表达式 → “为运算表达式添加括号”的小规模版 | 多位整数先分词，保留重复结果；完整 16 个运算符的规模控制在阶段 8 完成 |

### 验收与交给 AI 的要求

能独立完成叠盘子、LCS、两端取数和石子归并，并说明它们各自的状态及依赖。用等宽盘子、空前缀、单元素区间、奇偶回文检验边界。AI 应按表中顺序逐个模型展开，不直接给同时包含高精度和区间 DP 的另一版本“矩阵取数游戏”。表达式先验证小规模正确性，不以“会递归”代替完整数据范围下的算法评估。

### 应明确给 AI 的实现要求

- **精确小数幂**：从字符串读入，去掉小数点后按整数求幂，再恢复小数位。不能先转 `double` 再补精度。原题要求小于 1 时从小数点开始输出，小数末尾不留 0，纯整数不留小数点。
- **挂号系统**：状态至少能区分仍有预约、已签到候诊、已叫号；时间换成分钟，分别比较未迟到与迟到病人的规则。先写“签到是否成功”和“谁先叫号”两个小函数。`T≤1440` 时可先选清楚的线性扫描，不强制使用优先队列。

- **链表去重**：样例要求把原有连续重复块全部删除，例如 `1 2 2 3` 得到 `1 3`，不是各留一个。删除前保留下一个节点，不能访问已释放对象。

## 阶段 8：综合状态设计与考场训练——把模型组合到真实难度

### 入口与具体目标

已会递归/回溯、DFS/BFS、前缀和、背包与计数、序列/区间 DP、滚动数组、常见复杂度，以及阶段 7 的实现专题。会用小规模枚举验证答案，但尚未独立掌握下列压轴题的完整算法。

本阶段分三轮：**先补衔接题，再完成综合题，最后限时混合训练**。不能把“学过背包和 DFS”当成已掌握综合题；需要给出完整状态、正确性和符合原始范围的实现。

### 对应 Hello 算法章节

回看 13.1—13.4、14.2—14.6 中实际用到的方法即可。本阶段主要依靠原题与专门讲解，**没有一个 Hello 算法章节可以直接覆盖以下全部综合难点**。

### 8A：每道综合题的衔接阶梯

| 综合题 | 先做的衔接题 | 本题新增的关键能力 |
|---|---|---|
| 前缀奇值 | 给定 0/1 串统计奇数前缀和 → 固定选取数量的最小代价 DP | 抽象为奇偶性；证明目标奇偶序列的交换代价可化为所有改变位置的费用之和；同时约束奇数总数和奇前缀个数 |
| 邮票设计 | 固定面值的最少邮票数 DP → 递增枚举两三种面值 | 外层搜索面值，内层 DP 检验连续覆盖；限定下一面值范围、正确回退，统计全部最优设计 |
| 为运算表达式添加括号 | 阶段 6 小表达式 → 对同值结果合并方案数 | 控制组合结果规模；记忆化区间、按值聚合，并保留重复结果的数量意义 |
| 债务 | 计算三人的净收支 → 两人少量纸币重新分配 → 三人小规模分配 DP | 每张纸币的最终归属、金额守恒、按面额分组和状态压缩；在原题金额与张数限制下优化完整算法 |

### 8B：综合题的明确学习终点

**1. 前缀奇值：达到原题 `n≤500` 的状态设计。**

设原数组中奇数个数为 `m`。目标奇偶串必须仍有 `m` 个 1；改变奇偶性的位置可配成原奇变偶、原偶变奇的一对，通过一次交换实现，最小费用就是这些改变位置的 `c[i]` 之和。这个等价关系需要先证明，再写 DP。

可用“处理了前 i 个位置、放了 j 个奇数、产生了 k 个奇前缀”的最小费用作为学习方向；当前前缀奇偶性由 `j%2` 决定，不必再增加独立的一维。每位置尝试 0/1，完成所有 `k=0…n` 的答案。目标是 `O(n³)` 时间、滚动后 `O(n²)` 空间，并按题目多组数据总 `n≤500` 评估总工作量。AI 必须补全初始化、范围与不可达状态，不能只给“多维 DP”四个字。

**2. 邮票设计：搜索、检验、计数三部分都完成。**

首个面值必须为 1，其余面值严格递增，以免同一设计因排列被重复计数。已选面值能用至多 `m` 张覆盖 `1…R` 时，下一个面值最多为 `R+1`，否则缺口无法补上。用最少邮票数 DP 检查覆盖到哪里，区分“可达的最大金额”和“从 1 开始连续可达的上限”。

原题 `n≤6、m≤5`，还需安排范围界、缓存或增量更新等实际搜索效率训练；若使用最优上界剪枝，必须保留可能并列最优的分支。找到更优答案时重置设计数，遇到同优答案时累计。用较小 `n,m` 穷举对拍后，再测试原始上限。

**3. 添加括号：完成完整输入范围的规模控制。**

输入最多 16 个运算符，不能无评估地列出所有括号树，也不能在每个子区间只保留最小的 1000 个中间结果：后续减法、乘法可能需要较大的中间结果。

原题保证任意括号方式的中间值绝对值不超过 10000，可以研究“区间 → 结果值 → 方案数”的稀疏或值域计数表示；相同结果合并存储，方案数可在 1000 封顶，因为最终只输出排序后的前 1000 项。**封顶的是每个值的计数，不是直接丢掉较大的结果值。** AI 应解释组合计数、封顶为何保持所需输出正确，分析并实测最坏规模；不能把频数压缩自动当作已解决全部性能问题。

**4. 债务：完成净额建模与符合约束的优化算法。**

先将债务化成最终金额目标：`A原金额-ab+ca`、`B原金额+ab-bc`、`C原金额+bc-ca`；金额守恒，目标若为负则无解。求的是纸币**最终换了持有人**的张数，不能把传递过程中的每次交接都算一次，也不能只求总支付金额。

从“每张纸币分给 A/B/C，保留原主费用 0、换人费用 1”的小规模基线起步，再学按面额分组的转移。每个面额若原有张数为 `a,b,c`，最终张数为 `x,y,z`，则必须有 `x+y+z=a+b+c`；该面额最少换主张数为 `a+b+c-min(a,x)-min(b,y)-min(c,z)`。两人的金额可作为状态，第三人由守恒确定。

正式解还要利用总金额不超过 1000、只有六种面额、低面额张数限制，以及可达金额范围/模约束等优化。**逐张枚举所有金额对只作为小规模对拍基线，不能未经复杂度核验就声称能处理 50 组原题数据。** AI 应先讲清分组、范围裁剪或其他完整优化所需的新知识，再给可通过原始范围的实现；随后要求独立重写并解释每个状态。这是一项单独的难题训练，不是基础背包的一道普通同类题。

### 8C：与作业衔接的额外专题

这些题的知识需求超过两套期末的主要母题。按课程提交要求安排，不把它们提前变成前几个阶段的隐性门槛。

| 课程题 | 应先补的知识与学习方向 |
|---|---|
| 矩阵乘方和 | 整数快速幂 → 矩阵乘法与单位矩阵 → 同时递归求幂与幂和；取模和乘法中间结果。先用小矩阵，再处理 `k≤10^9` |
| 山区建小学 | 一维位置前缀和、连续一组由中位数服务的费用 → 预处理区间费用 → 按前缀和学校数划分 DP；不能把单组费用每次都重新遍历 |
| 最优路径 | 阶段 4 的网格 DP → 同一行从左/右的分别扫描，合并来自上一行的状态；不能在一张表里任意来回松弛 |
| 小游戏 | 棋盘外加一圈可走区域；把沿可通行直线的一次移动视作一条边做 BFS，或先补方向状态与 0-1 BFS；起终点占用与最少线段数需要专门处理 |
| 附加题：百万长度最长回文、鹰蛋 | 前者需在中心扩展后另学线性回文算法；后者需从朴素“楼层/蛋数”DP 转到“次数/蛋数能覆盖多少层”。不默认阶段 6 的 `O(n²)` 方法可处理百万长度 |

### 8D：限时训练与最终验收

1. **短混合训练**：先做 60—90 分钟的 3—4 题混合，隐藏模型标签；基础实现、搜索、DP、模拟交叉出现。基础题力争约 5—12 分钟，标准模型题逐步争取约 15—25 分钟，按个人实际耗时调整。
2. **至少两次 180 分钟、9 题模拟**：先保留一套未写过代码的真题。若两套都已见过，让 AI 按原卷比例选新题，不能简单改数值后当作新卷，也不提前标出算法。
3. **选题与止损**：先浏览并标记把握，完成可稳定拿下的题，再集中攻综合题；某题久无进展时记录当前状态并切题，给最后检查留时间。
4. **复盘四段耗时**：读题、建模、编码、调试；错误分为模型未识别、状态/证明错误、实现/边界错误、定位错误。下轮针对实际短板补题。

主要验收是：在未提示模型的混合题中能稳定识别并独立实现主要模型；两次整卷中的基础和标准模型题完成率稳定，逐步争取完成 6—7 题及以上。四道综合题都应完成原范围的精讲、验证与独立复写，并至少能将其中的方法迁移到一道变式；**整卷 9 题全解还需要由限时成绩验证，不能由“八阶段学完”直接推出。**
