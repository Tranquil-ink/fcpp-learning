## 魔王军队
*画图找思路*
每次从当前尚未覆盖的最左边元素开始，找到其右边R以内最后一个元素，把石头放在这
*把思路转化成代码*
```CPP
// 处理输入
// sort
// 
int left = 0;
int cur = 0;
int result = 0;
while (true){
    while (/* cur与left距离＜=R */&&/* cur<最后一个元素 */){
        cur ++;
    }
    
    //这时cur是下一个left，石头放在cur-1
    result ++; // put stone here
    // 如果这时cur已经到达最后，就可以结束了
    if (cur = 最后一个元素&&cur到left的距离<=r) break;
    left = cur-1;
}
```

s.substr(0, 5);                     // 返回 "Hello"；不修改 s
s.substr(6);                        // 返回 "World"；省略长度表示直到末尾
s.find("World");                   // 返回 6；找不到返回 std::string::npos
s.find('l', 3);                     // 从下标 3 开始找，返回 3
s.replace(0, 5, "C++");            // s 变成 "C++ World"
s.insert(5, ",");                  // s 变成 "Hello, World"
s.erase(5, 6);                     // s 变成 "Hello"；删除从 5 开始的 6 个字符
s.clear();                         // s 变成空串
//  `replace(pos, len, new_str)`：删掉旧的一段，再放入新的字符串，长度不必相同。**
