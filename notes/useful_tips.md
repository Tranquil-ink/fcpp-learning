# 代码习惯：
- 每个模块前注释一下
- 先写部分代码骨架，待实现部分先注释掉

- 模块化解耦代码，封装函数

- 变量名最好要说清它代表什么：cnt、sum、age 一眼能懂，像a1、b2很容易搞错。
- 缩进需要统一，否则容易弄错括号的层级。
- **数组的全局上界**写成const int MAXN = 1005，而不是a[1005],b[1005],c[1005]，以防打错   
**循环的上界**也建议写成全局的常量。

# 快捷键
- **shift+alt+f** 一键排版代码
- **shift+alt+a** 注释一块代码
