
| 写法 | 读取什么 | 空格、换行如何处理 |
|---|---|---|
| `cin >> n` | 一个数 | 默认跳过前面的空白 |
| `cin >> s` | 一个不含空白的字符串 | 跳过前面的空白，遇到空白停止 |
| `cin >> c` | 一个非空白字符 | 默认跳过空格、换行等 |
| `cin.get(c)` | 一个字符 | 空格、换行也会读取 |
| `getline(cin, s)` | 一整行 | 保留空格；读走行末换行，但不存入 `s`; 如果输入是一行空行，getline 会成功读取，得到：line == "" |


如果题意是“第一行只有数量，后面每行是一条文本”，推荐这样写：
```cpp
#include <limits>

int n;
cin >> n;

// 丢弃数量所在行的剩余内容，包括换行符
cin.ignore(numeric_limits<streamsize>::max(), '\n');
//如果用cin.ignore()一般也可以，它只会丢掉一个字符
for (int i = 0; i < n; i++) {
    string line;
    getline(cin, line);
    // 处理 line
}
```

5．读到输入结束，把“读取操作”放在循环条件里。
记住这三个模板：
```cpp
// 不知道有多少个整数
int x;
while (cin >> x) {
    // 使用 x
}

// 不知道有多少组，每组两个整数
int a, b;
while (cin >> a >> b) {
    // 使用完整读到的一组 a、b
}

// 不知道有多少行，空行也要读取
string line;
while (getline(cin, line)) {
    // 使用 line
}
```

读取成功才进入循环，可以避免使用没有成功读入的数据。

不要写成：
while (!cin.eof()) {
    cin >> x;
    // 使用 x
}

原因是：**尚未设置EOF状态，不代表下一次读取一定成功。**最后一次读取可能失败，而你仍然执行了循环体；遇到不符合类型的内容，也可能读取失败却没有到EOF。
另外，本地手动测试时，按回车只是结束一行，不会结束整个输入。所以 while (cin >> x) 在你输入一行后继续等待，通常是正常行为；评测系统会提供输入结束信号。
你之前笔记中关于 peek 的说法也应修正：
cin.peek()

只是查看下一个字符，不会取走它，也不会自动跳过空白。看到换行时，后面的 cin >> s 会尝试跳过换行，再读取字符串；换行本身不会导致它失败。是否成功，仍然应由 cin >> s 的结果判断。
6．逗号、括号等符号
如果格式固定，可以用 char 接收分隔符：
```cpp
//读取 (3,5) 可以写：
int x, y;
char left, comma, right;
cin >> left >> x >> comma >> y >> right;
``` 
如果一行有不确定数量的逗号分隔整数，可以先读整行，再拆分：
```cpp
#include <sstream>

string line;
getline(cin, line);

istringstream ss(line);
string token;

while (getline(ss, token, ',')) {
    int x = stoi(token);
    // 使用 x
}
```
```cpp
getline(cin, line);        // 从标准输入读到行末
getline(ss, token, ',');   // 从字符串流读到逗号
```
**它们都会读走分隔符，但不把分隔符存进字符串。**
如果某个字段可能为空，如 12,,35，就不能直接对空字符串调用 stoi，应按题意处理。

7．输入可能是不同类型时，先统一读成字符串。
```cpp
string s;
cin >> s;

if ('0' <= s[0] && s[0] <= '9') {
    int n = stoi(s);
    // 整数转罗马数字
} else {
    // 罗马数字转整数
}
```


又如：
输入：12.5

int n;
cin >> n;   // 读到 12，.5 留在输入流中

所以，变量类型要按题意选择；>> int 不会检查整段输入是否都是整数。

8．需要保留空格、换行等每一个字符时，使用 get。
```cpp
char c;
while (cin.get(c)) {
    // c 可以是普通字符、空格、换行等
}
while ((c = cin.get())!=EOF){}  //也行

//与它对比：
char c;
while (cin >> c) {
    // 默认跳过所有空白，只处理非空白字符
}
```

任务	适合的读取方式
统计英文大写、小写和数字数量，空白无关	cin >> c
逐字符保留原文格式	cin.get(c)
逐行识别 [Namespace] 等标签	getline(cin, line)


对第6题来说，标签以整行为单位，getline 比逐字符处理更方便。
9．多组数据中，即使已经知道答案，也要读完本组输入。
第5题有 t 组数据。下面这种思路可能让后续读取错位：
for (int i = 0; i < n; i++) {
    cin >> row;
    if (已经确定答案) break;
}

假如本组剩下的几行还没有读，下一组的 cin >> n >> m 就会遇到这些字母行。
比较省心的写法是先读完整组，再计算：
int t;
cin >> t;

while (t--) {
    int n, m;
    cin >> n >> m;

    vector<string> grid(n);
    for (int i = 0; i < n; i++) {
        cin >> grid[i];
    }

    bool found = false;   // 每组重新初始化
    // 处理本组数据
}

**算法可以提前停止，但输入不能随意少读。**每组使用的计数器、标记和容器也要重新初始化。
最后，关于读取失败，你目前理解到下面这一层就够了：**失败后，继续调用 cin >> ... 通常不会自动恢复；clear() 清除错误状态，ignore() 丢弃输入内容，两者作用不同。**例如交互程序想放弃错误的一行，可以写：
cin.clear();
cin.ignore(numeric_limits<streamsize>::max(), '\n');


在保证输入合法的考试题中，一般不用写完整的错误恢复流程。如果读取失败，先检查是不是选错了类型、漏处理了分隔符，或前一组数据没有读完。
对你这份样题，实际选择可以压缩为：
题目	推荐方式
1、2、7、9：数字输入	cin >> ...
3：无空格字符串	cin >> s
4：多条DNA序列	循环 cin >> s
5：多组字母矩阵	读 t，每组读完整个矩阵
6：含空行的文本	while (getline(cin, line))
8：数字或罗马数字	先 cin >> s，再判断类型


**编码前先判断两件事：空白是否属于有效内容，以及这一批输入靠数量、结束标记还是EOF终止。**这两点确定后，大部分输入代码都能直接选用上面的模板。
